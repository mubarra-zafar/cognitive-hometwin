# Cognitive HomeTwin

## Project Overview

Cognitive HomeTwin is a research prototype exploring how cognitive digital twins can be used to model human behaviour, identify behavioural changes, and support intelligent decision-making in smart-home environments.

The project explores the integration of smart-home sensor data, behavioural modelling and explainable AI to move beyond simple activity monitoring towards a deeper understanding of everyday behavioural patterns.

The broader aim is to investigate how cognitive digital twins could contribute to human-centered intelligent environments, particularly in the context of independent living and Ambient Assisted Living.

## Research Motivation

Smart-home environments generate continuous data through sensors and connected devices, providing insights into everyday activities and routines.

However, identifying unusual activity does not necessarily explain why a behavioural change has occured.

Cognitive Digital twins offer an opportunity to explore more intelligent approaches to behavioural understanding by combining behavioural modelling, pattern analysis, explainable AI and potentially causal reasoning.

This project investigates how such approaches could help identify meaningful behavioural changes and explore possible explanations, particularly in applications related to independent living and healthy ageing.
